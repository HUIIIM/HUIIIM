# HUIIIM (profile repository)

The GitHub profile repository for HUIIIM (Jiahui Miao): the public
profile README and profile surfaces only. It carries no product code.

## How work happens here

- Direction arrives in-repo: GitHub Issues labeled `jarvis-task`, PR
  review comments, and `CLAUDE.md` / `LOOP.md`. Read both at session start.
- External Claude works on `claude/*` branches and opens PRs; it never
  merges its own PRs. Jarvis reviews and merges.
- There is no branch protection here by design (profile automation pushes
  directly); content changes still go through PRs when a human or agent
  authors them deliberately.

## Working rules

- Profile copy follows the standard bio caliber: "Participates in 3GPP
  working on 6G core network standards; founder of vertciti, building N=1
  personal AI infrastructure." — shortened only where a surface enforces a
  character limit.
- Brand facts here must match vertciti.com the same day they change
  (all-platform real-time sync rule).
